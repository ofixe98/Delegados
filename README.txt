DELEGADO AFL — PWA V1

Esta pasta contém a versão web/PWA para teste.
Funciona no navegador e foi preparada para poder ser adicionada ao ecrã inicial.

IMPORTANTE:
O ZIP não é um link público. Para abrir no telemóvel como PWA, os ficheiros precisam de ser publicados num endereço HTTPS (por exemplo, através de um serviço de alojamento).

A versão já inclui:
- Início
- Dia de Jogo
- Checklist com memória local
- Regulamentos
- Pesquisa
- Incidentes
- Relatório simples guardado localmente
- Manifest PWA
